# 📸 Instagram Clone

Aplicación web tipo Instagram para compartir fotos, dar “me gusta”, comentar y gestionar perfiles de usuario.

---

## 🖥️ Características

- ❤️ **Like en publicaciones**  
- 📝 **Crear, editar y eliminar publicaciones**  
- 🧑‍💻 **Registro, login/logout y gestión de usuarios**  
- ✏️ **Edición de perfiles** (avatar, biografía, datos personales)  
- 📷 **Subida de fotos** con descripción y etiquetas  
- 💬 **Comentarios en publicaciones**  

---

## 🛠️ Tecnologías Utilizadas

- **Python** 3.9.16  
- **Django** 5.1.6  
- **Pillow** para procesar imágenes  
- **django-crispy-forms** para formularios  
- **Bootstrap 5** para diseño responsivo  
- **JavaScript** (vanilla) para interactividad (likes, comentarios asíncronos)  

---

## 🚀 Cómo Usar

### 1. Clonar el repositorio  
```bash
git clone https://github.com/AlbertoContento/Instagram.git
cd Instagram
```
### 2. Instalar requerimientos
```bash
pip install -r requirements.txt
```
### 3. Migramos y Ejecutamos el servidor
```bash
python manage.py migrate
python manage.py createsuperuser     # crea admin
python manage.py runserver

```
